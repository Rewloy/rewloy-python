# Güvenlik / Security

Bir güvenlik açığı bulduysanız lütfen herkese açık bir issue açmayın. Bu deponun
**Security** sekmesindeki **Report a vulnerability** düğmesiyle bize özel olarak
bildirin. Bildiriminizi alır, inceler ve sonucu size yazarız.

If you find a security vulnerability, please do not open a public issue. Report
it privately with **Report a vulnerability** on this repository's **Security**
tab. We will review it and get back to you.

Bu açık kaynak kütüphanedeki değil de Rewloy hizmetinin kendisindeki bir açığı
da aynı yoldan bildirebilirsiniz. / Vulnerabilities in the Rewloy service itself
can be reported the same way.
